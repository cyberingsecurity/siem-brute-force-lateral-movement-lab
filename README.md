# SIEM Brute Force and Lateral Movement Investigation

Portfolio write-up of a synthetic SSH brute-force and lateral-movement investigation in a local Dockerized SIEM training lab.

## Investigation report

[Read the full SIEM investigation report](siem-brute-force-lateral-movement-lab-report.md).

The report documents the event timeline, a validated threshold detection rule, generated alerts, limitations, and ATT&CK technique mapping. All telemetry is synthetic; no real systems were accessed or remediated.
